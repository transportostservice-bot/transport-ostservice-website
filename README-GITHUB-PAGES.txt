DATEIEN HOCHLADEN
1. ZIP entpacken.
2. Alle Dateien und Bilder direkt in das Hauptverzeichnis deines GitHub-Repositorys hochladen.
3. Wichtig: index.html muss direkt im Repository-Hauptverzeichnis liegen.
4. GitHub: Repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
